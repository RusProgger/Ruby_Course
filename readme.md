# 🚀 Основы Ruby — учебный курс

Добро пожаловать в курс по изучению языка программирования **Ruby**!

Этот курс предназначен для знакомства с Ruby с нуля и изучения основных принципов языка. Мы разберём базовые конструкции, научимся писать программы и поймём философию Ruby: **«всё является объектом»**.

---

## 📌 О курсе

**Уровень:** Начальный
**Язык:** Ruby
**Цель курса:** Получить крепкую базу для дальнейшего изучения Ruby и разработки приложений.

В процессе обучения мы изучим:

* ✅ синтаксис Ruby;
* ✅ переменные и типы данных;
* ✅ условия и циклы;
* ✅ методы;
* ✅ массивы и хэши;

# 📚 Программа курса

## 1. Знакомство с Ruby

* Что такое Ruby?
* История создания языка
* Установка Ruby
* Первый запуск программы

Пример:

```ruby
puts "Hello, Ruby!"
```

---

## 2. Основы синтаксиса

Изучаем:

* комментарии;
* переменные;
* числа;
* строки;
* логические значения.

Пример:

```ruby
name = "Ruby"

puts "Привет, #{name}!"
```

---

## 3. Условия

Работа с логикой программы:

```ruby
age = 18

if age >= 18
  puts "Доступ разрешён"
else
  puts "Доступ запрещён"
end
```

---

## 4. Циклы

Повторение действий:

```ruby
5.times do |i|
  puts "Шаг #{i}"
end
```

---

## 5. Коллекции данных

Работа с:

* Array;
* Hash.

Пример массива:

```ruby
languages = ["Ruby", "C++", "Python"]

languages.each do |lang|
  puts lang
end
```

---

## 6. Методы

Создание собственных команд:

```ruby
def hello(name)
  puts "Привет, #{name}!"
end

hello("Alex")
```

---

## 7. Объекты и классы

Главная идея Ruby:

> В Ruby всё является объектом.

Пример:

```ruby
class Player
  def initialize(name)
    @name = name
  end

  def info
    puts "Игрок: #{@name}"
  end
end

player = Player.new("Max")
player.info
```
